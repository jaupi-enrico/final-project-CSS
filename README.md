# Festival della Moda

Sito web statico realizzato con **HTML + CSS** per presentare un evento dedicato alla moda.

## Pagine principali

- `index.html` — Home con brand, notizie e location.
- `giornate.html` — Programma delle 7 giornate e dress code.
- `biglietti.html` — Tipologie di biglietti e prezzi (Visitatore / VIP).
- `acquisto.html` — Form di acquisto simulato.

## Tecnologie

- HTML5
- CSS3

## Avvio in locale

1. Clona il repository.
2. Apri `index.html` nel browser.

In alternativa puoi usare un server locale, ad esempio:

```bash
python3 -m http.server 8000
```

e visitare `http://localhost:8000`.

## Struttura del progetto

- `img/` contiene immagini e icone usate nel sito.
- `style_*.css` contiene gli stili condivisi e per singola pagina.
